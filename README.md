# Задание 4 — Четыре мира

Четыре отдельных адаптивных сайта с интерактивной схемой и учебным бронированием, HTML / CSS / Vanilla JavaScript (ES-модули). Без сборки, npm, регистрации, сервера бронирования и платежей.

## Темы

- `geek/` — GEEK.EXE: комнаты для настолок, D&D и гик-встреч, почасовая бронь.
- `gaming/` — RIFT ZONE: игровые зоны PC/консолей, почасовая бронь.
- `comics/` — Пятый кадр: авторские столы на фестивале комиксов, бронь на 1–7 дней.
- `japan/` — AO: домики в японском саду, бронь на 1–30 ночей.
- `index.html` — главная страница со ссылками на все четыре сайта.

## Запуск

Скачайте репозиторий и выполните в его папке:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Из-за ES-модулей открывать двойным щелчком через `file://` не следует. Внешний запрос только к Google Fonts; при отсутствии сети используются системные шрифты. Схемы и иллюстрации созданы вручную с помощью SVG и CSS, без внешних карт и платных API.

## Функции

В каждом сайте 8 объектов, 2 изначально заняты. Одна модель данных строит схему, список и карточку. Фильтры по вместимости и максимальной цене работают одновременно в обоих представлениях. Скрытый фильтром выбранный объект сбрасывается с сообщением. Пустой результат сопровождается подсказкой.

Свободно / выбрано / занято различаются текстом, символами и оформлением. Занятые объекты заблокированы. Выбор доступен с клавиатуры, фокус виден, у полей есть подписи.

Сумма обновляется при вводе срока. Участники и срок проверяются как целые числа в разрешённых пределах. Подтверждение создаёт единственную бронь, объект блокируется; повторная отправка не дублирует её. Отмена снова освобождает объект. Брони хранятся в отдельном ключе localStorage для каждого сайта, после обновления восстанавливаются. Повреждённое хранилище и запрет записи сопровождаются сообщением. Кнопка сброса запрашивает подтверждение и не затрагивает другие приложения.

## Ограничения

**Учебное демо: бронирования сохраняются только в этом браузере.** Реальная бронь не оформляется. Это вымышленные клубы, фестиваль и рёкан. Бронируется объект целиком до отмены, без календаря и проверки пересечений дат. Синхронизации между устройствами и вкладками нет. Фильтр цены относится к цене за единицу времени, а не к полной сумме. Два исходно занятых объекта освободить нельзя.

## Нейросеть и промпты

В работе использована ChatGPT (Codex): разработка концепций, HTML/CSS/JS и проверка поведения.

1. «Создай четыре разных сайта на HTML/CSS/ванильном JS: гик-клуб, игровой клуб, фестиваль комиксов и японский рёкан. В каждом интерактивная схема с 8 объектами и список из тех же данных. Два объекта заняты».
2. «Добавь два синхронных фильтра, карточку выбора, проверку участников и срока, живой расчёт стоимости. Подтверждение не должно создавать дубликаты».
3. «Добавь localStorage, восстановление, отмену с освобождением объекта, обработку повреждённых данных и недоступного хранилища. Проверь мобильную компоновку и управление клавиатурой».

## Проверка перед сдачей

Для каждого сайта: выбрать объект через схему и список, изменить срок и участников, проверить сумму, подтвердить, повторить подтверждение, обновить страницу, отменить и забронировать заново. Проверить недоступность занятых объектов, пустые/дробные/отрицательные поля, максимумы, оба фильтра, пустой результат, сброс выбора при фильтрации и сброс демо. На телефоне схема и карточка располагаются друг под другом.

## GitHub Pages

Публикация из ветки `main`, папка `/ (root)`. Сборка не нужна, файл `.nojekyll` отключает Jekyll. Относительные пути подходят для проектного GitHub Pages. Все четыре сайта доступны по подпапкам одного репозитория.

RIFT ZONE — киберспортивная арена с нижним пультом запуска сессии. «Пятый кадр» — газетная вёрстка с авторским рисованным комиксом и билетом-квитанцией.
